Service Provider Website

This project is a front-end web application built to connect users with household service professionals like plumbers, electricians, carpenters, and painters. The idea was to create a simple, responsive, and user-friendly platform where people can browse services, add them to a cart, and book them easily.

  Features
	•	Clean and Responsive UI – Works smoothly on desktop, tablet, and mobile devices.
	•	Service Listings – Displays essential services (plumbing, electrical, carpentry, painting) with pricing.
	•	Interactive Components –
	•	Search bar (location-based)
	•	Service cart with add/remove options
	•	Login form
	•	Sliders for services and customer reviews
	•	Customer Reviews – Shows feedback with ratings.
	•	Blog Section – Highlights service insights and achievements.
	•	Footer Section – Quick links, contact info, and newsletter subscription.

  Tech Stack
	•	HTML5 – Structure and content.
	•	CSS3 – Styling, layout, and responsiveness.
	•	JavaScript (ES6) – Interactivity and dynamic elements.
	•	Bootstrap – Responsive grid and UI components.
	•	Font Awesome & Material Icons – Icon library.
	•	Swiper.js – Sliders for services and reviews.

  Project Highlights
	•	Designed a user flow where customers can easily find, book, and review services.
	•	Implemented a responsive design to ensure accessibility across devices.
	•	Focused on usability and simplicity, making it beginner-friendly for both users and developers exploring front-end concepts.
	•	Great project to understand HTML/CSS layouts, JavaScript interactivity, and library integration.

  Learning Outcomes
	•	Hands-on practice with front-end web development (HTML, CSS, JS).
	•	Learned how to use external libraries like Bootstrap, Swiper.js, and Font Awesome effectively.
	•	Experience in creating a responsive and interactive design.
	•	Improved debugging, testing, and cross-browser compatibility skills.
